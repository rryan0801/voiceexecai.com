## Voice Commands (The Core Feature)

### How to Use Voice Commands
1. **Web Widget:** Click 🎤 button (bottom-right)
2. **Mobile:** Go to `/mobile` for full-screen interface
3. Hold to record, release when done
4. (Optional) Add context: prospect name, company, type of task

### Example Commands
- "Send follow-up email to John at Acme"
- "Schedule demo meeting for tomorrow at 2pm"
- "Create task to review Q2 proposal"
- "Generate proposal for Sarah, Tech Director at TechCorp"
- "Log call with prospect, discuss pricing"

### What Gets Executed
Behind the scenes, AI detects your intent and:
- Drafts emails using **your winning voice** (via Rep DNA)
- Creates calendar events (if Outlook connected)
- Generates proposals (using templates)
- Logs to CRM (Salesforce, HubSpot, Pipedrive)
- Creates tasks in your system
- Sends SMS/WhatsApp messages

### Real-Time Feedback
- **Live transcription** shows what was heard
- **AI reasoning** displays step-by-step thinking
- **Execution status** updates in real-time
- **Result card** shows what was done

### Prospect Readiness Pulse
**Path:** `/readiness-pulse`

Is this prospect **ready to buy NOW?**
- **Readiness score:** 0-100 (higher = more ready)
- **Pulse status:** Flatline, rising, peak, critical, declining

### Quiet Period Monitor
**Path:** `/quiet-monitor`

Catch deals going silent:
- **Critical silences:** 14+ days no contact

- **Channel analysis:** Which channels quiet? (email, SMS, LinkedIn)
- **Suggested interventions:** Video check-in, escalate, multi-channel blitz
- **Auto-alert:** Notified when deals turn critical

## AutoPilot: Hands-Free Follow-Up

### What Is AutoPilot?
**Path:** `/autopilot`

Autonomous multi-step follow-up sequences:
1. Voice command triggers sequence
2. AI drafts follow-up emails
3. Waits for prospect reply
4. If no reply after N days, sends next step
5. Tracks which steps get replies
6. Auto-escalates at decision moments

### Using AutoPilot
1. From any prospect record: **Launch AutoPilot**
2. System creates 3-step sequence automatically
3. **Pause/resume** as needed
4. **View progress** (steps completed, replies detected)
5. Manually edit steps if needed

**Best for:** Large prospecting lists where you can't touch each deal daily

## Tips & Best Practices

### Maximize Your DNA Score
1. **Use consistent phrases** across calls (build patterns)
2. **Ask discovery questions** at start (shows expertise)
3. **Acknowledge objections** before rebuttals (builds trust)
4. **Suggest timeline** for decision (creates urgency)
5. **Review your DNA** weekly to see what's working

### Coaching Application
1. **Before calls:** Read Objection Pre-Flight
2. **During calls:** Check Coaching Center for live tips
3. **After calls:** Log key insights to Conversation notes
4. **Weekly:** Review Coaching Effectiveness on Leaderboard

### Deal Velocity
1. **Accelerating deals:** Increase cadence (2-3x/week touches)
2. **Moderate deals:** Weekly touches, focus on objection handling
3. **Slow deals:** Deep dive on friction points (what's blocking?)
4. **Stalled deals:** Escalate or close loop (no-decision close)

### Email Quality
1. **Subject line:** Use prospect's pain point
2. **Opening:** Reference your last conversation
3. **Value prop:** Why YOU (not what you sell)
4. **CTA:** Clear ask (call, meeting, demo)
5. **Signature:** Your title and phone (makes it personal)

### Meeting Prep
1. **Research prospect:** LinkedIn, company website
2. **Run Meeting Copilot:** 15 min before call
3. **Review objections:** Practice 2-3 rebuttals
4. **Know your ask:** What's the next step?
5. **Prepare proof points:** Similar customer examples
