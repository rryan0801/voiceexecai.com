## 🆘 WHEN YOU GET STUCK

### Technical Issues
- **GA4 not tracking?** Check DebugView, verify tag in index.html
- **Resend not sending?** Verify domain, check DNS propagation
- **Site not indexed?** Request indexing in GSC, wait 24–48 hours

### Growth Plateaus
- **No signups?** Improve landing page CTA, add social proof
- **No activations?** Simplify onboarding, add activation email
- **No upgrades?** Add upgrade prompts, show Pro value earlier

### Content Blocks
- **No ideas?** Check competitor blogs, Reddit questions, Twitter threads
- **No time?** Batch write (4 posts in one session), use AI for outlines
- **No engagement?** Ask questions, share personal stories, be vulnerable
